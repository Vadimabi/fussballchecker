# Prozess: Review-Prozess

## Schritt-für-Schritt-Ablauf

1. Pull Request erstellen.
2. Reviewer zuweisen.
3. Feedback sammeln.
4. Änderungen vornehmen.
5. Merge nach Genehmigung.

## Rollen/Verantwortung

- Autor: Implementiert.
- Reviewer: Prüft Code und Doku.

## Review- und Änderungsregeln

- Mindestens ein Reviewer.
- Alle Kommentare adressieren.
