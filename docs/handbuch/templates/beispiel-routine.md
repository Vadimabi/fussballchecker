# Beispiel-Routine: Projekt starten

## Ziel

Ein neues Schülerprojekt basierend auf der Vorlage starten.

## Schritte

1. Repository klonen.
2. src/ anpassen.
3. Tests durchführen.

## Erfolgskriterien

- Projekt kompiliert und läuft.

## Fehlerbehandlung

- Kompilierfehler: JDK prüfen.

## Abhängigkeiten

- Java, Docker.
